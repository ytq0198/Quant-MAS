Part II · Data

数据验证管道 validate_ohlcv（M2）

多源抓取 → 统一 Schema

  • OHLCV：Stooq / YFinance · AAPL MSFT SPY
  • 宏观：FRED（DGS10 等）· SEC EDGAR JSON
  • 文本：Finnhub 新闻 → sentiment 信号表
$$\text{Raw} \xrightarrow{\texttt{validate\_ohlcv}} \mathcal{D}_{clean} \rightarrow \text{Parquet}$$

校验规则（LLM 上游、确定性执行）

  • 必需列：date, symbol, open, high, low, close, volume
  • 拒绝 high < low、负 volume、重复 date+symbol
  • 按 symbol 分组排序，保证时序单调
  • 输出 data/raw/market_data.parquet

脏数据在 Agent 介入前被拦截，避免「幻觉式策略」。

Part II · Strategy

规则基线：MovingAverageCrossStrategy

信号逻辑（long-only）

  • 快均线 MAfast（默认 5） vs 慢均线 MAslow（默认 20）
  • fast > slow → target_weight = 1.0（满仓该标的）
  • 否则 → target_weight = 0（空仓）
  • 按 symbol 分组独立计算，避免跨标的泄漏

Part II · Engine

BacktestEngine：确定性成交模拟

执行假设

  1. 策略输出 target_weight（T 日收盘后可知）
  2. 下一根 K 线开盘价 成交（无未来函数）
  3. SlippageModel 调整成交价 · CommissionModel 扣费
  4. 多标的：initial_cash 均分 · 权益曲线合并缩放

输出产物

  • equity_curve.csv — 每日权益
  • trades.csv — 成交明细
  • metrics.json — Sharpe、回撤、年化
  • 注册 ExperimentMemory → experiments.json

LLM 不可修改此引擎数学逻辑，仅可调配置参数。

LightGBM 方向模型（两种训练模式）

模式 A：单次时序切分（TrainModelTool）

  • train 70% / val 15% / test 15%（按时间）
  • 输出 train/val/test AUC、accuracy
  • server_lgbm_gpu_001：test_auc 0.479 ≈ 随机
  • → 说明不能只看 test 段，必须 WF OOS

模式 B：Walk-forward 每窗重训（主路径）

  • 每窗独立 fit LightGBM · device=cuda
  • 超参：n_estimators=100, lr=0.05, num_leaves=31
  • Train AUC ≈ 0.997 vs OOS AUC ≈ 0.472
  • → 过拟合可视化，支撑 OOS 必要性

Part II · RL/GRPO

GRPO：无 Critic 的组内策略优化（M7）

相对 PPO 的改进动机

  • PPO 需 Critic 估计 V(s)，金融噪声下易不收敛
  • GRPO 去掉 Critic，同状态采样 G 个动作/策略
  • 用组内收益排名计算优势，省显存、适合多 Agent

指标边界

GRPO 训练产物归属 simulation.* / training.*。不进 paper_main_results 主表。推广到 OOS 须走 M11.7/M11.8 候选验证桥。

裁剪目标函数 + KL 惩罚

$$J_{GRPO}(\theta) = \mathbb{E}\left[\min(r_i A_i, \text{clip}(r_i) A_i) - \beta D_{KL}(\pi_\theta \| \pi_{ref})\right]$$
$$A_i = \frac{R_i - \mathrm{mean}(R_{1..G})}{\mathrm{std}(R_{1..G})}$$

Part II · RL/GRPO

TradingEnv MDP 与奖励塑形

状态 St

$$S_t = \{X_{t-N:t}, w_{t-1}, Drawdown_t, M_{RAG}(t)\}$$
  • 多模态特征窗口 · 上一期权重 · 回撤 · RAG 检索上下文

动作 At

  • 离散：{Buy, Sell, Hold} 或 logits .argmax
  • 连续：目标权重向量 Σw=1, w≥0

奖励 Rt（Sharpe + 回撤 + 换手）

$$R_t = \frac{E[r_t]-r_f}{\sigma(r_t)} - \lambda_1 \max D_\tau - \lambda_2 \|\Delta w_t\|_2^2$$
