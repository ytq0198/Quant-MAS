01. 研究背景与开发动机

Motivation & Background

传统 AI 量化交易的两大行业痛点

  • 策略孤岛化严重： 传统的因子挖掘、信号生成、仓位管理与代码回测等开发环节高度依赖人工手工流转，彼此脱节，导致模型自动化进化迭代的效率极其低下。
  • “黑盒盲盒”悖论： 端到端的深度学习或纯大模型生成策略往往缺乏严密的金融学逻辑支撑。因模型决策链条不可知，在遭遇市场极端行情时，实盘的风控心理防线极易崩溃。

Quant MAS 的平台解耦架构思想

  • 核心分离原则（Core Separation）： 在底层架构设计上，将“确定性的量化计算（Deterministic Computation）”与“生成式的智能体研究编排（Agentic Orchestration）”进行彻底解耦、物理分离。
  • 安全第一防线： 确立全链路刚性边界，绝不赋予大语言模型（LLM）直接触碰或下发实盘订单的权限，让 AI 释放创新力的同时保证资金绝对安全。

02. 系统核心设计原则

Key Design Principles (Derived from architecture.png)

1. 智能体不触碰底层交易

根据架构图刚性约束，LLM Agent 在系统内简而言之不直接提交任何实盘订单。智能体层仅扮演“量化研究员”的职能，负责顶层路径规划、编排工具链、自动解释回测报告以及检索实验记忆群。

2. 确定性引擎硬核承载

所有涉及数据流清洗（`validate_ohlcv`）、高频分布式回测、多因子计算与极端风控指标监控，均由底层强类型的确定性计算引擎独立执行，确保精度无损，彻底绝缘大模型产生的“幻觉”。

3. 严格的多维指标物理隔离

严禁实验指标交叉混淆！训练集拟合度与样本内模拟指标仅作为策略候选集的演进参考。系统强制规定：只有流经滚动外推评估（Walk-forward OOS, oos.*）的纯净指标，才能支撑学术论文或实盘决策。

4. 链路层全向可审计追踪

设计了完善的日志链（Audit JSONL）。智能体的每一次工具调用（ToolRegistry）、代码变异控制与策略生命周期更迭均留下确定性数字脚印，确保研究产物完全可复现、可审计、可追溯。

03. 平台 8 层系统架构全景总览

System Architecture Layered Breakdown (Mapping architecture.png)

系统采用高内聚、低耦合的纵向 8 层协同演进架构，各层权责划分极为明确：

Layer 8
输出与人工审核层 (Outputs / Human Review)： 回测多维报告、滚动外推数据报告、可审计日志。引入 Human Confirmation 机制。
Layer 7
编排与协议层 (Orchestration / Protocol Layer)： M4 研究工作流（固定的 6 节点 DAG 调度）、M13 MCP 任务调度器。
Layer 6
智能体群落协同层 (Agent Layer)： 监督智能体 (Supervisor)、研究智能体 (Research)、研报智能体 (Report) 异步多角色协作。
Layer 5
原子工具箱层 (Tool Layer)： 数据摘要、回测引擎、模型训练调度、自动化风控检测、ML回测等全栈原子工具组件。
Layer 4
高维记忆与 RAG 层 (Memory / RAG Layer)： 混合检索器 (HybridRetriever)、Hash Embedding、内存向量库 (pgvector)、关系图谱 (Neo4j)。
Layer 3
研究与实验管线层 (Research / Experiment Layer)： 实验记忆体 (ExperimentMemory)、基线策略注册表 (BaselineRegistry)。
Layer 2
量化引擎计算层 (Quant Engine Layer)： 强数据验证器 (`validate_ohlcv`)、量价/宏观特征工程、传统ML预测模型群、Risk 隔离层。
Layer 1
异构数据源基础层 (Data Layer)： 多源网络抓取器（Stooq, YFinance, FRED）、结构化流式高效存储（Parquet, JSONL）。

04. 数据层清洗与确定性计算引擎基石

Data Layer Validation & Deterministic Computation Engine

强类型数据流验证管道

数据源进入系统后，必须强制流经底层确定性量化引擎的静态验证算子：

$$\text{Heterogeneous Raw Data} \xrightarrow{\quad\mathbf{validate\_ohlcv}\quad} \mathcal{D}_{\text{clean}} \in \text{Parquet / JSONL}$$

该验证模块运行于大模型上游，自动对缺失值、高低价严重倒挂、异常跳空进行清洗，从源头封杀因脏数据引发的 AI 策略误判。

三大核心安全防线细则 (Safety Boundaries)

  • 安全防线 1： LLM Agents cannot directly place live orders. 智能体层任何时候绝不被授予交易 API 密钥，仅生成实验策略代码。
  • 安全防线 2： ToolPolicy denies shell / broker / secrets. MCP 调度层对高危 shell 系统指令、越权读取账户命令执行硬性强力拦截。
  • 安全防线 3： Only audited OOS metrics support paper conclusions. 只有通过独立审计节点认证的滚动外推指标才能入库，根绝虚假优化的花哨报告。
技术亮点：量化引擎基石

05. 机器学习模块：多模态异构特征矩阵融合

Multi-Modal Heterogeneous Feature Engineering & Baseline Models

为了使策略生成具备宏观与新闻视野，系统在引擎层构建了时序资产价格与非结构化宏观文本舆情的联合融合特征空间：

多模态联合特征空间数学表达

$$\mathbf{X}_t = \begin{bmatrix} \mathbf{F}_{\text{technical}}(t) \\ \mathbf{F}_{\text{macro}}(t) \\ \alpha \cdot \mathbf{E}_{\text{FinBERT}}(\text{Text}_t) \end{bmatrix} \in \mathbb{R}^{(d_1 + d_2 + d_3) \times T}$$

其中，$\mathbf{F}_{\text{technical}}(t) \in \mathbb{R}^{d_1}$ 表示传统的量价时序动量、高阶波动率算子；$\mathbf{F}_{\text{macro}}(t) \in \mathbb{R}^{d_2}$ 代表 FRED 抓取的多维宏观经济周期标尺；$\mathbf{E}_{\text{FinBERT}}(\text{Text}_t) \in \mathbb{R}^{d_3}$ 代表通过金融垂直大模型对新闻/财报语料抽取的非结构化高维情绪特征，$\alpha$ 为动态调节权重。

06. 深度学习核心：基于 LoRA 的垂直领域适配

Low-Rank Adaptation (LoRA) for Agent-Level Local Models

垂直微调的技术核心

为了让本地开源大模型（如 DeepSeek、本地 vLLM 部署模型）在 `Agent Layer` 能够写出严密的量化代码并深刻理解财报，系统集成了轻量化低秩适配（LoRA）微调技术。

这种设计在冻结核心大模型百亿级参数主干的前提下，实现了极低算力开销下金融策略生成和长文本推理准确率的内生级蜕变。

低秩权重矩阵分解数学公式

在基础大模型原有权重 $W_0 \in \mathbb{R}^{d \times k}$ 旁路并联低秩训练矩阵：

$$W = W_0 + \Delta W = W_0 + \frac{\alpha}{r} (B \cdot A)$$

其中，矩阵 $B \in \mathbb{R}^{d \times r}$ 且 $A \in \mathbb{R}^{r \times k}$。其中设置极小固定的秩阶数 $r \ll \min(d, k)$，使得反向传播的梯度仅作用于极小的低秩伴随矩阵上，从而极大加速了策略智能体（ResearchAgent）的内生进化速度。

技术亮点：深度学习核心

07. 强化学习决策机制：时序马尔可夫规约

Reinforcement Learning Portfolio Management & MDP Formulation

为了让系统智能体在多变的金融市场中学会最优化资产调仓与头寸管理，平台引入了动态强化学习机制。其马尔可夫决策过程（MDP）规约如下：

1. 高维复合状态空间 (State Space, $S_t$)

为了给智能体提供全面的市场画像，状态向量构建包含：

$$S_t = \left\{ \mathbf{X}_{t-N:t}, \mathbf{w}_{t-1}, \text{Drawdown}_t, \mathbf{M}_{\text{RAG}}(t) \right\}$$
  • $\mathbf{X}_{t-N:t}$：历史 $N$ 期的多模态特征矩阵流。
  • $\mathbf{w}_{t-1}$：智能体组合在前一交易日的实际持仓权重。
  • $\text{Drawdown}_t$：当前账户实时面临的净值最大回撤。
  • $\mathbf{M}_{\text{RAG}}(t)$：RAG 层实时检索到的产业链上游实体风险传导图谱。

2. 双规约动作空间 (Action Space, $A_t$)

根据不同交易场景的需求，系统支持智能体输出双重空间动作：

  • 离散择时动作空间： $$\mathcal{A}_{\text{discrete}} = \{ \text{Buy (1)}, \text{Sell (-1)}, \text{Hold (0)} \}$$
  • 连续投资组合调仓空间： 用于管理大资金跨资产多标的头寸分配： $$\mathcal{A}_{\text{continuous}} = \left\{ \mathbf{w}_t \in \mathbb{R}^M \ \middle|\ \sum_{i=1}^M w_{i,t} = 1, \ w_{i,t} \ge 0 \right\}$$
技术亮点：强化学习决策

08. 强化学习核心：广义夏普与回撤惩罚奖励

Reward Shaping with Generalized Sharpe & Maximum Drawdown Penalty

传统的端到端强化学习极易引发严重的过拟合或恶意扛单。Quant MAS 设计了包含风险收益比、回撤硬惩罚以及换手率摩擦控制的综合奖励函数 $R_t$：

$$R_t = \frac{\mathbb{E}[r_t] - r_f}{\sigma(r_t)} - \lambda_1 \cdot \max_{\tau \in [0, t]} (D_\tau) - \lambda_2 \cdot \| \mathbf{w}_t - \mathbf{w}_{t-1} \|_2^2$$

🟢 1. 广义夏普算子

引导模型最大化风险调整后净值收益，而不是一味盲目追求极致暴利，保证策略具备抵抗时间平移的稳健性。

🔴 2. 最大回撤严厉惩罚

$\max(D_\tau)$ 项代表历史高点到当前时段的最大净值回撤。一旦模型产生严重的抗单或风控越线，奖励直接面临断崖式暴跌，强制智能体学会及时止损。

🔵 3. 换手率二次型约束

通过二范数惩罚相邻权重的剧烈漂移 $\Delta \mathbf{w}$。该项有效抑制了因大模型瞬时噪点产生的频繁调仓冲动，将交易摩擦成本压制到极低范围内。

技术亮点：强化学习核心

09. 策略种群进化：代码级交叉与变异机制

Strategy Population Evolution & Code-Level Crossover/Mutation

多模态策略群自动孵化

系统拒绝单一死板的参数搜索，而是由 ResearchAgent 注入多元化的提示词引导，结合实验记忆库（`ExperimentMemory`），在种群候选池（Population Candidates）中进行自动代码级演进：

$$\text{Strategy}_{\text{parent}} \xrightarrow{\quad\mathcal{M}_{\text{LLM}}(\epsilon)\quad} \text{Strategy}_{\text{mutated}}}$$

代码变异（Mutation）： 智能体定位现有逻辑的薄弱因子，自适应修改局部的代码逻辑或重构特征工程算子。

代码杂交（Crossover）机制

当基线策略注册表（`BaselineRegistry`）筛选出两个互补且 Sharpe 优秀的独立策略时：

  • 系统执行代码合并协议，剥离策略 A 的均线择时逻辑核心，与策略 B 的高阶高频波动率控仓逻辑。
  • 在智能体沙箱中将二者交叉重组为更高维的新一代群落后代，实现量化智慧的自主演进。
技术亮点：策略种群进化

10. 种群屏障：高维哈希与汉明淘汰算法

Diversity Protection via High-Dimensional Hash Embedding & Hamming Distance

核心痛点： 多智能体策略演进极易触发代码逻辑的“局部收敛”，导致大模型生成大量名字不同、但因子与代码逻辑高度雷同的同质化策略（近亲繁殖）。

哈希汉明多样性保护算法（Diversity Guard）

系统创新的引入高维文本与特征拓扑哈希嵌入技术，将新生成策略的代码全文本结构抽象映射成定长的二进制高维编码 $\mathcal{H}(\text{Strategy}) \in \{0, 1\}^L$。通过计算其与群落已有策略的汉明距离（Hamming Distance）执行硬风控：

$$D_H \left( \mathcal{H}(S_{\text{new}}), \mathcal{H}(S_i) \right) = \sum_{j=1}^L \left( \mathcal{H}_j(S_{\text{new}}) \oplus \mathcal{H}_j(S_i) \right)$$

🚨 自适应硬性防线：一旦满足 $\min_{i} (D_H) < \gamma$（即检测到空间结构高度同质化），系统判定该策略冗余，触发刚性机制直接予以强行淘汰，确保策略库的生物多样性！

技术亮点：种群进化屏障

11. 严格指标分流看板与可审计消融测试

Metrics Separation Ledger & Open Source Summary

全面落实 architecture.png 的规范，为了防范量化研究中普遍存在的数据窥探与伪过拟合，系统对指标命名空间执行严格物理隔离：

指标命名空间 核心技术对应场景 平台刚性审计与混淆拦截规则
